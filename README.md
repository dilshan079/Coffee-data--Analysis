# ☕ Coffee Sales Dashboard

An interactive **Coffee Sales Dashboard built using Microsoft Excel** to analyze coffee sales, revenue, orders, customers, countries, and yearly performance.

## 📊 Project Overview

This project analyzes coffee sales data from **January 2019 to August 2022**.

The dashboard provides a business-focused view of:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Sales by Coffee Type
- Sales by Country
- Annual Revenue
- Year-over-Year Growth
- Top 5 Customers
- Monthly Sales Trends
- Customer Loyalty

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Charts
- Data Cleaning
- Data Analysis
- Dashboard Design

## 📁 Dataset Structure

The Excel workbook contains the following sheets:

### 1. Dashboard

Interactive final dashboard containing key business KPIs and visual summaries.

### 2. Orders

Contains transaction-level sales information.

Main columns:

- Order ID
- Order Date
- Customer ID
- Product ID
- Quantity
- Size
- Unit Price
- Sales

### 3. Customers

Contains customer information.

Main columns:

- Customer ID
- Customer Name
- Email
- Phone Number
- Address
- City
- Country
- Postcode
- Loyalty Card

### 4. Products

Contains product-level information.

Main columns:

- Product ID
- Coffee Type
- Roast Type
- Size
- Unit Price
- Price per 100g
- Profit

### 5. ChartData

Contains summarized data used for dashboard visualizations.

### 6. Charts

Contains visual analytics charts used in the project.
